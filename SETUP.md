# Puestario: set up the agent, then close the box

**Use the managed installation for new clients. This release still needs the real Mac-and-phone pilot before client handover.**

Your two administrators keep control. Staff get only the work you approve. The agent cannot rewrite the programs that enforce these limits.

```text
PREPARE THE MAC → OPEN SETUP → CONNECT + TEST → CLOSE SETUP → READY
                       ↑                            │
                       └──── a founder can reopen ───┘
```

## Before the office visit

Prepare the Mac, dedicated phone, model account, app logins and backup key. Download the reviewed software and build the container. Write down the first useful job. Finish provider approvals first.

**Thirty minutes is the target for a prepared visit. It is not a tested promise yet.** A fresh Mac, missing passwords or custom integrations can take longer.

## At the office

1. **Power and internet — 5 minutes.** Run the machine checks.
2. **Phone and owners — 5 minutes.** Link the dedicated phone. Confirm both administrator accounts. Only one founder needs to be onsite; verify both accounts during preparation.
3. **Company and apps — 7 minutes.** Open Setup. Give the agent its name. Connect the approved app and check the correct account.
4. **People and first job — 8 minutes.** Add a test staff member. Test private chat, the staff group and a short reminder. Test that private information stays private.
5. **Backup and handover — 5 minutes.** Check recovery evidence. Close Setup. Leave only when the result says Ready.

If a check fails, fix it or leave the installation paused. Do not skip a check to finish the clock.

## What you can say

| An administrator say | What happens |
|---|---|
| “Open Setup for 15 minutes.” | Opens the protected setup tools for that founder. |
| “Call this agent Alex.” | Changes the shared agent name. |
| “Add Ana at this number. Let her read the sales sheet.” | Adds Ana with that permission only. |
| “Add Ana to this approved staff group.” | Updates the group and its sender list. |
| “Remove Ana.” | Stops new access and her pending scheduled work. |
| “Send my sales report at 8 AM.” | Saves a real job with the recipient and time zone. |
| “Close Setup.” | Checks acceptance evidence before marking Ready. |

Either founder can act alone. After access changes, send **/new** to begin a fresh chat. This keeps old private information out of the new permissions. Company-wide instructions are visible to every agent session: never put a password or private note there.

If the model is unavailable, the direct commands still work: `/desk status`, `/desk open 15`, `/desk close`. The detailed guide also shows direct add/remove commands.
