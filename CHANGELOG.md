# Changelog

## 0.2.0-pilot

- Replaces the earlier prompt-based layout with the managed installer and protected company state used by the website guide.
- Generates all seven OpenClaw instruction files and installs both required plugins from one reviewed source tree.
- Uses generic administrator examples; imports no founder decisions or reference-company memory.
- Keeps staff work inside explicit app/person/group grants. No payment, customer-email or unrestricted computer tools.
- Encrypts recovery snapshots before optional Drive upload. Restores pause delivery and disable jobs.
- Adds an example-config install guard, public-data checks, bilingual starting guides, architecture pictures, security contact, contribution instructions and release checklist.
- Requires a real Mac/phone/app pilot before client handover. No completed live pilot is claimed.

This is a new-install pilot, not an in-place migration of an existing company folder. See [upgrade notes](docs/CLEANUP.md).

## Initial public template

The initial public snapshot used `core/` and `client/`, seven instruction rules, manual placeholders and legacy backup scripts. Its MIT license is retained. Those files are retired from the active tree; prior public commits are unchanged.
