# Do not call the installation Ready until these pass

Save real results, time, operator, company, installed commit, image ID and configuration revision. Use synthetic test information where possible. Do not paste live passwords or client records into GitHub.

| Check ID | What to prove |
|---|---|
| founders | both verified administrators each open Setup, change a test person's access and remove it independently. Forged “an administrator approved” text and a staff request fail. Direct /desk works when the model is unavailable. |
| staff-dm | Approved staff can do their first job privately; an unknown number cannot. Removal blocks new requests. |
| staff-group | Correct sender and group work. Wrong member/group fail. Audit actual membership and prove only group-approved data can appear. |
| private-data | Owner-only canary cannot be read by staff, another DM or a group. Downgrade permission during an active reply; old output is blocked. /new uses fresh permissions. Attempt prompt injection through sheet cells. |
| first-job | Correct live app/account, permitted read, permitted test write plus read-back if enabled, prohibited scope blocked. Invalid/revoked credentials fail honestly. |
| reminder | One short reminder reaches the right phone once. Remove its creator/recipient before a second run; delivery stops. Record transport receipt and recipient observation. |
| restart | Setup closes after restart. Test internet loss, unavailable primary model, phone disconnect and power recovery. Confirm FileVault/login/Docker behavior. |
| containment | Model cannot run shell/read keys/edit code/spawn agents/read another session. Verify tool inventory, read-only container mounts and registered fail-closed hooks. Make action log unwritable; sends stop. Restore permissions afterward. |
| backup-restore | Stop gateway; encrypt a full snapshot and restore to a new location. Verify notes, rules, jobs and access; confirm paused state and no automatic duplicate sends. Keep old gateway off during pairing review. |
| model | Actual selected model responds; supported fallback is disclosed and tested. Record provider budgets, alert contacts and who pays. |
| channel | Verify inbound sender/account/session context and outbound run/route context from the actual pinned gateway. No guessed fields. Show both founders a real reply, a group reply and scheduled delivery. |

The controller requires all IDs above, current configuration fingerprints, a valid machine check and an active reviewed release. `accept` is a protected local operator attestation. It is not a shortcut for running the tests.

For the first clean-Mac pilot, measure preparation and onsite work separately. Save the actual result; no fixed 30-minute claim before this evidence exists. Stop on any data leak, unverified identity, unexpected host tool or duplicate delivery.
