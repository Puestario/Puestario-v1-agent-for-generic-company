# Built now, next, later / Hoy, después, más adelante

This is a plan, not a list of installed features. Keep the current desk focused on one useful client job. Each addition needs a real owner, approved data, a narrow tool, tests and live acceptance.

## Built now — qualify with a live pilot

Scoped Sheets read/write, Calendar read, Stripe charge read, GHL contact read; private notes; reminders; bounded single-source reports; founder/staff/group controls; encrypted backup and paused restore. See [release status](RELEASE-STATUS.md).

## Next — prove the installation

1. Prepared Mac, dedicated phone, actual model and one business app: complete [acceptance](ACCEPTANCE.md).
2. Verify both founders, staff/group privacy, access removal, restart and denied tools using the running model.
3. Observe delivery, recovery and failures. Measure the visit before promising 30 minutes.
4. Agree on support, account ownership, recurring costs and offboarding for that client.

## Later — build only for an agreed job

| Desired job | What is still needed |
|---|---|
| Staff staff profiles and company knowledge | Source ownership, person-level access, reviewed updates, search/retrieval tool, deletion and retention rules. Old seed memories must not be imported by default. |
| Owner morning/end-of-day business brief | A real source for every metric, complete pagination/time ranges, reconciliation and a checked readable report. Current single-source output is bounded raw data. |
| Meta Ads, Make, email, finance or other apps | Reviewed app adapters, minimal sign-in scopes, failure handling and evidence. Connector notes alone are not an integration. |
| Calendar changes or additional internal tools | Separate scoped tools, approved fields, tests and read-back after writes. Money movement and customer messaging stay outside this profile. |
| Voice notes and photos | Media consent, retention, transcription/vision pipeline and reliable identity/context handling. Current replies are text only. |
| Telegram backup | Verified sender mapping, separate routing/session rules, media/delivery tests and a real switch-over exercise. |
| Automatic backups and stronger monitoring | A safe stopped-gateway backup window, restart checks, tested scheduler, alerts and periodic restore drills. Drive upload alone does not schedule backups. |
| Fleet updates and cost controls | Per-company rollout/rollback, runtime compatibility tests, MDM setup, provider limits and combined usage tracking. |
| Specialist agents or another runtime | Separate role permissions and evidence; do not import broad role prompts as authority. |

## Retired methods

Do not bring back model-supplied identity, unrestricted shell/desktop tools in this staff profile, credentials in chat, plaintext backups, one shared private memory for all staff, or two competing installation guides.

## Español

**Después:** terminar las pruebas, medir la visita y acordar soporte, gastos y entrega de cuentas.

**Más adelante:** perfiles del equipo, informes para el dueño, más aplicaciones, audios, Telegram, copias automáticas y administración de varios equipos. Cada función necesita permisos claros y pruebas; no aparece por agregar un documento.

**Retirado:** claves en chat, identidad escrita por el modelo, herramientas sin límites y memoria privada compartida con todo el equipo.
